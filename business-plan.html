Toronto Painters: expansion plan

We want to open up to 50 paint branches. Each one runs the same way. We start with 2 or 3, and add more only when they work.

What we are building

  • One software (ROK) for quotes, signed contracts, invoices and receipts.
  • One agent on WhatsApp for leads and daily reports.
  • One playbook for how to price, sell and paint.

The money we need

Setup per branch: 700$ one time

Advertising per branch: 7,000$ a month [to confirm: per branch or total?]

For 50 branches, setup is 35,000$. Advertising would be 350,000$ a month if 7,000$ is per branch. If 7,000$ is the total, it is 140$ per branch.

What we must prove first

We test with 2 or 3 branches for [90] days. We need three numbers to be good:

  1. How many leads each branch gets per month: [ __ ]
  2. What each lead costs us: [ $__ ]
  3. How many paint jobs each branch must close per month to pay for its advertising: [ __ ]

How we roll out

  • Step 1: pilot with 2 or 3 branches.
  • Step 2: if the three numbers are good, open [__] more.
  • Step 3: open the rest in small groups, checking each group first.

The risks

  • We spend on ads before jobs pay. We cap spending until a branch breaks even.
  • Branches do the work differently. Everyone uses the same playbook and software.
  • Cheap leads that never buy. We track cost per real lead, not per enquiry.
